# CEVRA

CEVRA is a proprietary agent-assisted video creation and editing platform designed for an intuitive desktop-first experience with mobile companion support.

## Product principles

- Modern, flat and restrained UI; no generic “AI dashboard” aesthetic.
- PT-BR and EN-US from day one, with extensible internationalization.
- Project IR is the canonical source of truth.
- Engines and external services are isolated behind versioned adapters.
- AI agents decide; deterministic engines execute and validate.
- Core editing must not require paid OpenAI/Anthropic API usage.
- Commercialization-safe dependency and provenance policy.
- Signed in-app updates; no normal reinstall workflow.
- Desktop and mobile share the same project model and design system.
