# Composition Engine

Composition implementations remain behind `CompositionEngineAdapter`. HyperFrames is a preferred candidate only if the ADR 0012 benchmark proves functional and visual parity or superiority against the Remotion-based behavior documented by the public [`fillrochaa/edvid` `SKILL.md`](https://github.com/fillrochaa/edvid/blob/main/SKILL.md). If it does not, CEVRA may select Remotion or another suitable engine. Remotion is not currently incorporated and requires review of the proposed version's then-current license for compatibility with CEVRA's proprietary commercial distribution before selection. CEVRA project state must not depend on any engine-specific source representation.
